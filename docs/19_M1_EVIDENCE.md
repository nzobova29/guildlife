# 19. Первый frontend-спринт — результат и проверки

**Дата:** 05.11.2026 (Europe/Moscow). **Ветка:** `feat/GL-005-visual-shell`. **Статус:** локально реализовано, готово к просмотру; не опубликовано и не принято автором как релиз.

## Что изучено

README, CONTRIBUTING, CHANGELOG, все 19 исходных документов `00`–`18`, три CSV, инструкции доски и шаблоны GitHub. Просмотрены все восемь PNG-концептов и WebP-обложка. В исходном репозитории был один коммит документации, рабочее дерево чистое; кода и тестов не было.

Выбран уже описанный первый спринт, GL-005–009. Основание: пользователь поручил изучить материалы и приступить к работе. Исследования с пользователями и внешняя Project Board не выполнялись и не считаются подтверждёнными.

## Реализовано

- React + TypeScript + Vite, фиксированные версии и npm lockfile.
- Sidebar, ресурсная панель, шесть разделов с hash-навигацией.
- Город: четыре отдельных SVG-здания, HTML-hotspots, свободный участок, улицы, деревья, набережная. Исходные концепты не используются как фон.
- Кампания: название, описание, срок, недельная ёмкость; валидация, отдельный этап проверки, редактирование перед подтверждением, отмена без добавления.
- Квесты: локальное создание, редактирование, завершение, фильтры, пустое состояние; выбор связанной кампании.
- Нативные диалоги, Escape, восстановление фокуса, фокус на заголовке проверки, видимые focus rings, reduced motion.
- Мобильная компоновка; навигация в два ряда, без слияния длинных подписей.
- Панели Архитектора и строительства объясняют недоступность функций. Ни реальных, ни выдуманных AI-заданий нет.
- Конфигурация GitHub Actions для frontend. Удалённый CI ещё не запускался.

## Граница реализации

Все данные — локальные примеры в памяти React. Reload сбрасывает изменения, что явно написано в интерфейсе. Кошелёк всегда **40 монет / 0 XP**. Числа наград в карточках — предварительные значения из GDD, начисления нет. В M1 не реализованы PostgreSQL, сессии гостей, API, AI, покупки, ledger, аналитика, таймер и канбан. Сквозные backend QA-кейсы не закрыты UI-тестами.

Loading и сетевые ошибки не имитируются, поскольку нет асинхронных API-операций. GL-008 уточнён: M1 — валидация/предпросмотр/подтверждение; реальные сетевые состояния — M2.

## Проверка в настоящем браузере

Playwright CLI + Chromium, локальный Vite-сервер. [Сценарий](../output/playwright/m1-smoke.js) и [результат](../output/playwright/m1-smoke-result.txt): 28 проверок. Это автоматизация браузера для текущего спринта; не полноценный MVP E2E suite.

- Переходы из всех четырёх зданий и свободного участка.
- Отклонение пробельного заголовка.
- Tab не активирует элементы фона при открытом нативном диалоге; browser chrome может получать фокус — это штатное поведение Chromium.
- Escape закрывает форму и возвращает фокус к вызвавшей кнопке.
- Проверка кампании получает фокус; сохранение происходит только после принятия.
- Завершённый квест повторно недоступен, баланс не меняется.
- После перезагрузки локальная задача исчезает согласно маркировке демо.
- Все шесть разделов без горизонтального overflow при 1280×720 и 390×844.
- Форма помещается по ширине 390px; длинная форма прокручивается внутри диалога.
- За проверяемый прогон нет исключений JavaScript (`pageerror`).

## Обзор и исправления

Независимый агент выполнил read-only review исходников и повторил тесты/lint/build. Critical-проблем не найдено. Замечание по контрасту основных кнопок подтверждено вычислением: прежняя светлая часть градиента давала 2.92:1 для белого текста. Новый градиент даёт **6.03:1–5.08:1**; hover — **5.08:1**. Это проверка данного компонента, не полный аудит WCAG.

Дополнительно исправлены перекрытие подписей зданий, лишняя заливка SVG-контуров и подтверждённая браузером потеря фокуса на переходе формы к проверке.

Незначительное замечание отложено: CTA «Добавить первый квест» в карточке кампании открывает общую Гильдию; форма квеста позволяет выбрать кампанию вручную. Предзаполнение кампании можно добавить в следующей итерации.

## Технический долг и незавершённые условия

- `npm audit` сообщает 10 moderate предупреждений в dev-инструментах ESLint/TypeScript-ESLint. Общий источник — транзитивный `minimatch@10.2.6`, advisory `GHSA-g3hv-75wg-m249`. Не выполнялся принудительный major override до проверки совместимости. Эти пакеты не входят в production JS приложения.
- Художественная детализация исходных концептов выше текущего SVG-прототипа; окончательная визуальная приёмка остаётся за автором.
- Не проводились интервью, полноценный screen-reader/WCAG аудит, кроссбраузерные тесты и замеры производительности.
- Нет внешних Issues/Project Board, публикации, PR или remote CI evidence. Задачи GL-005–009 находятся в **Review**, а не Done.
