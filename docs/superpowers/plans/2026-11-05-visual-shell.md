# M1 — интерактивная оболочка GuildLife

> Исполнение: superpowers:executing-plans, в текущем проекте, по задачам ниже.

**Цель:** реализовать первый спринт из `docs/17_SPRINT_01.md`: город, навигацию, панели и формы на демонстрационных данных.
**Архитектура:** React + TypeScript + Vite; SVG-сцена с отдельными зданиями, HTML-кнопками и панелями. Локальное состояние сбрасывается при перезагрузке. Серверная экономика и AI остаются M2/M3.
**Спецификация:** `docs/02_PRD.md`, `docs/04_USER_JOURNEYS.md`, `docs/15_VISUAL_SYSTEM.md`, `docs/17_SPRINT_01.md`.

## Ограничения и решения

- Указание пользователя изучить материалы и приступить к работе — основание начать описанный первый спринт. Не обозначаем исследования, внешнюю доску или весь M0 завершёнными.
- Четыре здания: Академия, Гильдия, Ратуша, Лаборатория; один свободный участок.
- Цвета из визуальной системы; фиксированная изометрия 2:1, тёплые окна, городские кварталы.
- SVG создаётся в коде отдельно от концептов; исходные макеты не становятся фоном приложения.
- Кампании и квесты редактируются только в памяти. Деморежим виден всегда. XP/монеты остаются образцом, покупки и AI недоступны с объяснением.
- Формы не имитируют сетевые задержки и успешные API-запросы. Состояния загрузки/ошибки сервера принадлежат M2.
- Основной путь: город → Академия → форма → проверка → локальная кампания → Гильдия.

## Что проверить особенно внимательно

Пустой/пробельный заголовок, отмена предпросмотра, неизменность кошелька при локальном завершении, возврат фокуса из диалога, ширина 390px без горизонтального скролла.
