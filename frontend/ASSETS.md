# Ресурсы первого спринта

| Ресурс | Источник / метод | Использование |
|---|---|---|
| `src/components/BuildingArt.tsx` | SVG-геометрия написана для проекта при AI-assisted разработке | Отдельные Академия, Гильдия, Ратуша и Лаборатория; общая точка привязки, изометрия 2:1 |
| `src/components/CityMap.tsx` | SVG-геометрия написана для проекта | Улицы, площадки, деревья, фонари, набережная |
| `public/favicon.svg` | SVG написан для проекта | Знак башни GuildLife |
| Иконки | `lucide-react`, ISC, см. установленный пакет LICENSE | Единая система UI-иконок |
| Шрифт | Системный стек, без загрузки внешних файлов | Русский и английский интерфейс |

Концепты из `../assets/concepts/` изучены как визуальные ориентиры и не включены в bundle. Права на их публичное распространение по-прежнему требуют отдельного решения автора. Приложение не загружает изображения, шрифты или аналитику со сторонних адресов.

Камера: фиксированная; горизонтальные оси проецируются в отношении 2:1. Общий SVG footprint зданий — 240×250, якорь внизу по центру; названия — отдельный HTML. Финальный художественный polish не является условием подключения M2.
